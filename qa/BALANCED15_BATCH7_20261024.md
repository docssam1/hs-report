# 활용 1회 난도별 15개 — 7차 검수

원문 19~21번에 하·중·상 5개씩 45문항을 추가했다. 20번의 기존 승인 중 5개를 재사용하고 19·21번은 모두 새로 제작하여 신규 40개다. 누적 21유형 315문항은 기존 80개 재사용과 신규 235개다. 기존 승인 1,935개를 보존하며 전체 고유 저장은 2,170개다. 활용 270유형 중 249유형 및 다른 시리즈는 아직 미완료다.

## 원문과 설계

현행 문제 PDF 4쪽과 교사 답안 19~21쪽을 직접 열었다. 원문 배점은 모두 3.4점으로 보존한다. 새 연습은 별도 제작 기준 2.7/3.4/4.2이며, 학생 실측 정답률이나 원문과의 난도 동등성이 실측됐다고 주장하지 않는다. 신규 문항마다 조건·구할 대상·답 계약·상세 풀이·학습 연결과 아홉 가지 난도 차이를 기록했다.

- 19번: 위쪽 엑스면과 오른쪽 엑스면을 구분해 대면 관계·회전·한 선과 세 선의 방향을 검산했다. 원문 정답 ②④⑤와 일치한다. 하는 한 대면/이웃 관계, 중은 윗면·앞면의 두 조건 배치 수, 상은 오른쪽까지 세 조건의 배치 수다. 원문 보기 다섯 개를 반복 문항으로 세지 않았다. 원본 전개도 영역을 원래 해상도로 추출했고, 그 안의 모든 선·점·무늬·색을 보존했다. 새 라벨·완성 입체·보조선은 넣지 않았다.
- 20번: 하는 합집합을 직접 주어 겹침을 계산한다. 중은 기존 승인 5개를 그대로 보존했다. 상은 전체 분할 비, 밥 전체와 빵 전체의 차, 밥만/빵만 먹은 수의 배수를 결합해 교집합을 역산한다. 원문 답 20명과 실제 인쇄 분수도 확인했다.
- 21번: 원본은 세로 5열×7행, 가로 10열×2행인 십자 격자다. 하는 높이 한 칸과 고정 너비, 중은 고정 너비의 모든 높이, 상은 가로>세로·넓이 하한·둘레 상한을 함께 적용한다. 상은 어느 조건을 빼도 후보 수가 늘어난다. 독립 모델의 원문 직사각형 540개가 교사 답과 일치한다. 그림은 변형하지 않았다.

## 검산·출력·연결

315개 답을 독립 검산했다. 이번 범위는 전개도 BFS 접기와 24개 정상 회전, 정수 인원 분할, 원본의 모든 단위 경계선으로 만들 수 있는 직사각형 전수 열거다. 도형은 실제 원본 영역과 픽셀을 대조했다. 이전 270개 전체 내용·답·풀이·저장 버전과 기존 은행 전체 바이트를 보존했다.

PC 1440/375, 315개 문제와 풀이, 원본 그림 90개, 난도 필터, 실제 2단의 좌상→좌하→우상→우하 순서와 잘림 0건을 확인했다. 신규 45개의 정오 채점·3회 제한·최초 기록·학습 위치/포인트·해당 15개 연습 경로를 검사했다. 원시험 오답 19/20/21번의 새 연결과 기존 활용 1~5회 3/9개 경로, 원시험 성적 보존, 권한·registry·칼럼 보존, 외부 쓰기 0건을 확인했다. 기존 9개 은행의 19/21번 잠금은 바꾸지 않았다.

실제 다운로드한 ZIP 7항목의 315개 ID, 선택 문항의 전체 내용, 문제·풀이·CSV 순서가 일치한다. 문제 69쪽·풀이 119쪽이며 양면 묶음에서는 빈 면 하나 뒤인 71쪽에 풀이가 시작한다. ZIP의 188쪽을 모두 렌더했다. 이전에 직접 검수한 실제 ZIP과 같은 350px 렌더의 내용 영역을 비교해 동일한 157쪽의 시각 검수를 이어받고, 바뀐 31쪽을 직접 축소판·확대로 확인했다. 바뀌는 머리말·바닥글은 별도 표본 검수했다. 이 비교는 수학·입력 검수를 대신하지 않는다. 공개 상태로 바꾼 뒤에도 ZIP의 전체 선택 데이터와 모든 PDF 쪽의 그림·배치 스트림 일치를 검사했다.

공개 전 19번 상 문항 한 개의 9px 넘침은 같은 조건을 간결하게 표현해 해결했다. 21번 상 풀이의 ‘가로 띠 밖’ 오기는 ‘가운데 세로 띠 밖’으로 정정하고, 수정한 실제 ZIP을 다시 생성·검수했다. 그림이나 글꼴을 줄이지 않았다.

누적 진행은 `qa/balanced15-progress.json`, 실제 main·Pages·공개 파일·Drive 원본 재읽기는 비공개 7차 영수증에 남긴다. 다음 22~24번 원문과 교사 답도 직접 읽었다. 다음 제작에서는 22번의 승인 5개는 중, 23/24번의 승인 5개는 상에 보존해야 한다. 이 사전 대조를 새 15개 제작·승인으로 세지 않는다.
