## 원문과 난도 설계

- 현행 문제PDF6쪽 중25~28번은5쪽,29~30번은6쪽,교사 답안PDF8쪽 중해당6문항은7쪽을 직접 열었다.28번은원본Im89의정면5칸·높이3칸·깊이3칸을 확인했고,원본230×139픽셀·선·색·시점을 그대로 쓴다. HWP변환은 없다.

- 26번:하는두나이차를 직접 주고 합에서 막내 나이를 구한다. 중은막내 출생 때 큰형/둘째의3배관계와 두형의6살차에서 두차를 먼저 도출한다. 기존 상은다른 두시점의관계와 미래나이를 결합한다. 세나이를 별도 정수탐색으로 확인했다. 출생해0살과 원문성적은 보존한다.
- 27번:하는두인수가 모두 보이는3자리×2자리 세로셈의 첫부분곱,중은2□5·5□와 첫부분곱에서 빈자리를 역산한 뒤 전체곱을 구한다. 기존 상은부분곱과 최종곱의 여러자리 단서를 함께 추적한다. 표시한 세로셈5개 행의 숫자·빈자리·자리수를 직접 파싱하고 자리별 곱/올림과 두부분곱의 덧셈으로 유일해를 검산했다. 풀이 순서나 조건 요약을 문제 아래에 붙이지 않는다.
- 28번:하는세길이가 정해진 위치세기,중은한길이 고정/정사각형 정면/정육면체 분류,상은짝수부피·모서리관계·길이합·단위칸 포함/제외 조건을 결합한다. 원문 전체540개를 여섯 경계의 직접 열거로 확인했다. 새상5개는380/218/28/140/132개이며 길이별 위치·홀수부피 여집합·제외할 모서리칸의 계산을 상세풀이에 적었다. 단위칸이나 정답 위치를 문제 그림에 표시하지 않는다.
- 29번:하는짧은숫자열,중은1~12/14/16/18/20의 실제 전체 연결열,기존 상은1~100의 긴 연결열이다. 지울 수·선두0 금지·남은순서를 보존한다. 앞자리 선택 창과 별도 take/skip 동적계획을 대조하고 짧은열은 모든 부분열도 열거했다. 긴정수 답은문자열로 저장·입력·채점해 정밀도를 잃지 않는다.
- 30번:하는6장중2장,중은9장중3장의 경우를 세도록 개수비와 합의비를 모두 준다. 기존 상5개는12장중4장이다. 문제에 표시한 카드값과 매개변수를 대조하고,부분집합 열거와 별도 개수/합DP로 확인했다. 주머니A/B는구별하고 안의순서는 구별하지 않는다. 실제 가능한짝/세수·가장큰카드별 분류는 답안에만 둔다.
- 원문25~30번 배점4.2와 새연습2.7/3.4/4.2를 따로 기록한다. 신규65개는9축 난도 차이를 적었고,원문과 동등한 대체문항 또는 실측정답률이라고 주장하지 않는다. 기존 승인25개는원래필드를 그대로 보존한다.
