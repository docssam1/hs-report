# Final3 30문항 상세 풀이 통합 계약

## 범위

- 검수된 상세 풀이는 파이널 3회 1–30번을 모두 포함합니다.
- 기존 채점용 `answer`는 바꾸지 않습니다. 이름·단위가 포함된 `displayAnswer`는 문항별 독립 승인 대응표와 정확히 일치할 때만 표시합니다.
- 원본 문항, 채점, 점수, 통계, 학생 기록, Final1·Final2 상세 풀이를 변경하지 않습니다.

## 로드와 공개 범위

1. `mock-data-final.js`를 기존 문항·정답의 기준으로 불러옵니다.
2. 3회에서만 앞부분 그림, 뒷부분 그림, 상세 풀이 데이터, 공용 상세 렌더러를 차례로 불러옵니다.
3. Q1·3·4·6·7·8·13·17·18·19·24·25·26·30은 문항에 묶인 정확한 SVG 모델·계산·렌더가 모두 있을 때만 풀이를 엽니다.
4. 독립 검수와 원본 재계산을 마친 1–30번은 `releaseStatus: eligible`로 일반 성적표에서 엽니다.
5. 24번은 기존 채점값 `614`를 그대로 두고 학생용 답에는 여덟 기호 값을 모두 표시합니다. 30번은 색칠 방법 수가 아니라 최소 색 수인 `4색`으로 표시합니다.
6. 표시 답이나 채점 답을 느슨하게 정규화하지 않습니다. 번호별 정확한 두 문자열 중 하나라도 다르면 해당 문항을 잠급니다.

## 검증

```text
node qa/final3-detailed-data-validate.js
node qa/final3-diagram-registry-validate.js
node qa/final3-detailed-renderer-validate.js
node qa/final234-report-integration-validate.js
```

브라우저 검사는 일반 주소와 로컬 미리보기에서 모두 준비 완료 30/30, 390px 표·그림 가로 넘침 없음, 14개 필수 그림 누락 시 해당 문항 잠금, 인쇄에서 30문항 상세 풀이가 모두 들어가는지 확인합니다. 실제 A4/PDF 생성과 문항별 전체 교육 내용 보존 검사는 별도 폴더에서 수행합니다. 이 문서만으로 배포 완료를 주장하지 않습니다.
