# 활용1회1~15번 · 원문당 하·중·상5개씩225문항

13~15번45문항을 추가했다. 이 원문들은3.4점이므로 기존 승인15개를 중 단계에 보존하고 하15개·상15개를 새로 만들었다. 누적225개는 신규160개·승인65개 재사용이며, 기존1,935개 고정 은행을 보존한 고유 저장 문항은2,095개다. 활용1~9회270개 원문 중15개 원문만15개 구성이 끝났고,255개 원문과 다른 시리즈는 남아 있다.

현행 문제PDF3쪽과 교사답안13~15쪽을 직접 대조했다. 13번은 실제 원문이 숫자카드를 텍스트로 주는 문항이며,15번은 나열된 분수의 분자/분모를 약분하지 않고 읽는다. 도형이나 원본 그림은 바꾸지 않았다.

- 13번: 백의 자리 둘을 고정한 최대곱 → 기존 두 세 자리 수 곱의 최대·최소차 → 두 수 차의 범위와7의 배수 조건을 동시에 적용한 최대·최소차. 상5개는 두 조건이 각각 실제 양 극값에 영향을 주고 무제약 극값을 재사용할 수 없음을 확인했다.
- 14번: 첫 봉지 양에서 두 번 순방향 계산 → 기존 전체 양에서 마지막 양 역산 → 전체와 마지막 양에서 첫 양·공통 증가량을 함께 역산. 모든 단계에서 원문의 연속된 세 배 관계를 유지한다.
- 15번: 보이는 앞부분의 빈 분수 찾기 → 기존 큰 순서의 분수 찾기 → 분자/분모 합과 차로 항을 찾은 뒤 전체 순서 역산. 하·중은 분자/분모 두 칸, 상은 순서 한 칸으로 답안 입력을 구분했다.

새30개에9개 난도 축과 기초 보완/확장 관계를 기록했다. 원문3.4점과 연습2.7/3.4/4.2점을 분리하고, 실제 학생 정답률이나 동등 난도 대체물이라고 주장하지 않는다. 정답은 실제 세 자리 수의 숫자 마스크와 겹치지 않는 인수쌍, 첫 봉지 양의 정수 전수조사, 분수를 한 항씩 만드는 상태 전이로 독립 검산했다. 카드 그림의 수치와 분수 초기17항도 실제 표시 자료와 대조했다. 앞180개 본문·답·풀이·연습 저장버전은 그대로다.
