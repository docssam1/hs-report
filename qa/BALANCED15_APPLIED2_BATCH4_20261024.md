# 활용2회19~24번 난도별15개 확장

19~24번 각각 하·중·상5개씩 추가하여 활용2회1~24번360문항을 연결한다. 이번90개는 신규85개와 기존 승인23번5개 재사용이다. 앞270개 전체 필드·저장버전,활용1회435개와 기존 승인 은행을 보존한다. 누적53유형795문항이며 활용217유형·다른 시리즈는 미완료다.

## 원문·단계별 사고

- 현행 문제PDF6쪽 중19~23번은4쪽,24번은5쪽을 직접 대조했다. 교사PDF8쪽 중19~20번은5쪽,21~24번은6쪽을 직접 읽었다. PDF 재변환은 없다. 원문 배점은19~22번3.4/23~24번4.2이며 새 연습2.7/3.4/4.2와9축 차이를 별도 기록한다. 실측 난도·정답률로 주장하지 않는다.
- 19번은 원본10칸의 두(2,3,1)예시를 그대로 사용한다. 하의 지정 칸 상태,중의 양끝/중간 빈칸 관계,상의 서로 다른 두 그림의 공통 칸·순서 없는 짝을 구분한다.1024개 이진 배열의 직접 열거와 여백 조합을 따로 비교했다. 전체10그림과 짝 개수 표는 답안에만 둔다.
- 20번은 원본5원·9영역·오른쪽8을 보존한다.1~9한번/각원합11의 배치는 유일하다. 하에는 실제 국소 조건을 주어 한 원의 나머지 수를 찾고,중은 영역 합·곱·차,상은 원래 한 원 영역 합35/겹침 합10과 변경 뒤 두 총합을 결합해 두 배수를 역산한다. 바꾼 뒤 개별 원 합까지 같다고 가정하지 않는다.
- 21번 원본 모빌의 막대·실·12방울·ㄱ/32g를 보존한다. 별도 유리수 소거의12무게식으로16,16,32,32,32,32,16,16,8,8,16,32g을 확인했다. 하의 지정 방울,중의 두 무게 개수,상의 세 무게 개수·차·전체 무게를 분리했다. 새 방울 묶음은 처음 그림과 다른 준비물임을 지문에 둔다.
- 22번 실제 세 접기는 위쪽 정사각형을 대각선 두 번으로 접고 아래 직사각형을 위로 올리는 구조다. 작은4원은 각각5개의 완전한 원,큰 반원은1개의 완전한 원과3개의 테두리 홈으로 이어진다. 원본 화살표·접는선·검은 부분을 바꾸지 않고,세 반사와 실제 원 경계로21/3을 독립 확인했다. 하의 지정 절단,중의 두 절단 방식,상의 세 방식·완전원·홈 합계를 구분한다. 펼친 구조도는 답안에만 있다.
- 23번 현행 원문은 정확히10자리의1반복수와9반복수다. 새 하는 한 자리9의 곱,중은 두 자리99의 이동·받아내림을 사용하며 기존 승인 상5개는 그대로다. 표시된 실제 숫자열과 자릿수를 확인하고 세로 곱의 자리별 누적으로 독립 검산했다. 큰 수만 늘려 난도를 올리지 않는다.
- 24번은 익명 보관함의 일대일 대응 문제다. 하3개/2속성,중4개/3속성,상5개/3속성으로 조건 추적을 확장한다. 실제 한글 단서표를 다시 파싱하여 독립 CSP로 전체 대응의 유일성을 확인했다. 모든 문항에서 단서 하나를 빼면 다른 배치도 가능하다. 문제의 빈 대응표와 답안의 정답표를 분리하고,구체적인 번호 후보 제거와 대응 풀이를 제공한다. 학생 이름·명단을 사용하지 않는다.

## 출력·입력·연결 검수

- 360개 독립 답·전체 답집합·표시자료 대조·기존270개 전 필드/저장버전·33보호파일 검사가 통과했다. 원시험 답·점수·회원·권한·칼럼은 바꾸지 않는다. 표시 내용 중복0이다.
- PC1440/폰375에서360문제·상세풀이,원본 그림240개,답안전용SVG60개,세로셈15개·순위표15개·가격표5개·논리단서표15개·빈답안표15개·풀이표20개를 확인했다. 각 난도120개 선택,최대15칸 실제 답 입력·순서 채점,3회 제한·최초 기록 보존·학습 위치/포인트·풀이·추가 연습을 검사했다.375px에서 실제 논리 문제와15칸 입력도 캡처했다.
- 풀이SVG는 원래 가로세로비에 맞는 실제 폭·높이를 먼저 예약한다. 화면의 `object-fit`에만 기대던 고정220×240상자는 ZIP에서 원을 타원으로 늘리므로 제거했다.60개 SVG의 DOM 상자 비율 검사와 실제 ZIP의 원·정사각형·45도 절단선 확대를 통과했다. 이전 Drive 출력은 버전 기록으로 보존하고 현재 권장 출력은 이 수정본이다. 원래 문제 그림과 문제 데이터는 변하지 않는다. 재발 방지 규칙과 릴리스 게이트에도 반영했다.
- 실제 ZIP7항목,360개 문제·정답·상세풀이·CSV·목록ID와 선택 데이터가 일치한다. 문제109쪽·상세풀이188쪽의 전수축소판과 실제 확대를 확인했다. 그림 비율 수정 전후 문제109쪽의 이미지 바이트·배치 스트림도 모두 일치한다. 원본 그림240개와 풀이SVG60개의 HTML 내장 바이트가 자산과 같다. 최종 릴리스 상태에서 모든 선택 데이터 및297쪽 PDF가 검수본 그대로임을 재검사했다.
- 2단은 왼쪽 위→아래 뒤 오른쪽 위→아래 순서다. 기본6/4칸,긴 상·짝비교·모빌·접기와24번 단서/답안표는 필요 시2칸을 쓰며 두 단을 유지한다. 풀이에는 문제용 고정 빈칸을 넣지 않고 내용 길이대로 이어 쓴다. 양면 묶음의 답안 시작은 홀수 쪽이다. 검색형 PDF 모든 쪽에서 한글 텍스트도 확인했다.
- 원시험1~5회 오답 진단과 자료실의 활용2회24개15문항/기존14개9문항 연결을 실제로 확인했다.1회29개 색인·435문항과 기존216문제 표시/선택9개 ZIP 회귀,권한계약·registry20·칼럼21·소스 어댑터 계약도 통과했다. 운영 외부 쓰기0건이다.
- 고유 저장2565개/활용 고유1305개다.795개 균형 구성은 신규630개와 기존165개 재사용으로 나뉜다. 원문당9문항이 있는 기존 은행의 초과분도 보존한다.
