# 난도별 5개, 총 15개 — 현행 자료 점검

사용자의 후속 `늘리라고` 지시에 따라 **원문마다 하·중·상5개씩, 총15개**로 작업을 진행한다. 추가 질문을 반복하지 않는다. 아래 최초 착수 점검의 ‘단위 확인 중’ 상태는 해소됐으며, 기존 원문당9개 완료를 새 목표 완료로 간주하지 않는다.

## 1차 실제 확장 — 활용1회1·2·3번

- 세 원문 각각 하5/중5/상5, 총45문항을 구성했다. 기존 승인15개를 재사용하고 중·상30개를 새로 작성했다. 기존9개 은행은 그대로 두므로 기존 미선택4개도 삭제하지 않았다.
- 양손 왕복: 앞으로 세기 → 지정 손가락의 다음 세 수 역추론 → 배수·범위 조건을 합친 횟수. 숫자 세기: 세 자리 구간 → 자릿수가 바뀌는 구간 → 배수 제외 조건. 달력: 다음 달 요일 → 평년/윤년의 두 달 뒤 → 두 달의 날짜 합으로 요일·윤년 여부 함께 추론. 별도 단계형 확장으로 표시하며 원문과 동등 난도라고 포장하지 않는다.
- 새 연습 배점과 원문2.7점은 별도 저장했다. 실측 정답률은 없으며 제작 난도 추정이다. 원본 손 그림은 그대로 사용했고 원문·답안1~3번을 직접 열어 대조했다.
- 손가락 이동 시뮬레이션·나머지 상태 숫자DP·1900~2399년 실제 달력으로45개 답을 독립 검산했다. 서로 다른 답이 동률인 숫자 세기 후보는 제작 중 제외했다. 새30개에는9축 차이 기록이 있다.
- 실제 브라우저45개·풀이45개·원본 손 그림15개, PC1440/폰375, 난도 필터, 세 칸 답 입력, 최대3회·최초보존, 진단→학습위치→15개 링크, 원시험 저장 불변·외부 쓰기0건을 검사했다. 자료실에 준비된3유형만15개 링크를 추가했다. 기존5회차 진단/9개 연습 경로와 활용1회216개 렌더도 회귀 통과했다.
- 실제 ZIP은7항목, 문제9쪽/상세풀이16쪽, 문항ID45개가 문제·풀이·목록에서 일치한다. ZIP PDF를 직접 꺼내 전수 축소판과 위험 페이지를 확대 확인했다. [문제·상세풀이 ZIP](https://drive.google.com/file/d/1aS4gCnRKBmox4TEhjcdxlUFbXM0WTCN_/view), [검수 근거](https://drive.google.com/file/d/1P0VjAXj7T8jKrtMs6s8zFDUhG0mYKx6C/view).
- 전체 고유 저장 문항은 기존1,935+신규30=1,965개다. 15개 구성이 끝난 유형은3개이며 활용1~9 목표270유형 중 나머지267유형과 다른 시리즈는 미완료다. 원문별 전용15개를 각기 검수하는 목표를 회차 한 묶음15개로 줄이지 않는다.
- main·배포 완료는 별도 후속 영수증으로 확인한다. 이 문서 작성 시 로컬 검수와 Drive 업로드까지 진행했다.

## 현재 근거

- 기준 main `6005177756d0950e36a8d02ec12ae1a53ba81825`.
- 원문 목록 900개, 공개 저장 은행 19개, `verified` 상태 저장 문항 1,935개를 실제 데이터에서 읽었다. 색인 JSON을 문항으로 중복 계산하지 않았다.
- 기존 14개 은행은 420원문 ×3개=1,260개, 활용1~5 은행은 75원문 ×9개=675개다. 저장 상태를 읽은 것이며 기존 전체 검수를 새로 완료했다는 뜻은 아니다.
- 원문별 5/5/5 수량을 갖춘 곳은 0개다. 특정 난도에 9개가 있어도 다른 두 난도의 부족분으로 대신 세지 않는다. 기존 초과분은 보존 대상으로 계산한다.
- 활용1~9의 270원문에 원문별15개를 적용하면 목표4,050개다. 현행 활용675개는 원문 배점대 한 난도에만 있으므로 그중375개가 각 난도 상한5개 안에 들어간다. 나머지300개는 기존 보존 문항이며, 단순 기준 분류로 계산해도 목표 자리3,675개가 비어 있다. 새 변형의 난도 검수까지 완료된 수량으로 오해하지 않는다.
- 전체900원문에 원문별15개를 적용한 가정에서는13,500개 목표 중 기준상 빈 자리11,865개다. 이는 범위를 확정한 제작 약속이나 실제 난도 검수 통과 수량이 아니다.
- 서로 다른 원문을 섞은 **회차별 한 시험지15개**를 가정하면 19은행 중18은행은 기준 분류별5개 이상이 있다. 최종3회는 원문 기준 정답률에 따른 하0/중18/상72개라 하5개가 부족하다. 기준 정답률은 유사문항 실측 난도가 아니다. 이 점검은 새 시험지·입력·진단·ZIP을 만들거나 연결하지 않았다.
