# 최종 실전 4회 완료·연결 검수 (2026-10-22)

## 범위와 결과

- 대상은 자료실 최종 실전 `last|4`이다. 별도 파이널 `final4` 데이터를 재사용하지 않았다.
- 기존 48개 초안의 오류를 수정하고 남은 42개를 완성해 원문 30유형 × 3개 = 90개를 `bank/data/last4-reviewed.json`에 고정했다. 공개 시점에 새 문제를 생성하지 않는다.
- 새 그림이 필요한 유사문제의 그림 39개와 원본 공통 그림 재사용 6개, 조각 채우기 풀이 그림 3개를 확인했다. 원본 시험지·그림·정답·통계·학생 성적은 수정하지 않았다.
- 난도는 원문의 핵심 관계·단계와의 비교 판단이다. 실제 학생 대상 난도 측정이나 별도 사람 승인 완료를 뜻하지 않는다.

## 연결과 출력 계약

- 로드맵·자료실: 기존 영상 왼쪽/시험지 오른쪽 화면, 타이머·답안·분석 진입 경로 유지.
- 답안 입력: `last1-entry.html?round=4`, 기존 공식 1차와 재입력 2·3차 구분. 원점수와 교사 최초 기록 보존.
- 진단: 실제 오답에서 최대 3유형을 추천하고 화면에 각 3개를 표시한다. 높은 정답률 오답이 1~2개일 때도 다른 실제 오답으로 최대 3유형까지 채운다. 같은 목록을 학습 계획·학습 위치·QR·출력에 사용한다.
- 모든 원문 30문항에 기존 교재표의 실제 학습 위치와 회차별 학습 포인트를 연결했다. 권장 위치는 기초 학습 연결로 표시하며 교재 쪽수를 새로 추정하지 않는다.
- 기본 문제지는 2단 × 세로 3문항, 왼쪽 위→아래 다음 오른쪽 위→아래 순서다. 전체 90개는 문제 15쪽과 표지 1쪽이다.
- 답안은 문항별 연속 배치다. 전체 묶음의 답안은 물리적 17쪽(홀수)에 시작한다. 전체 PDF는 30쪽이며 문제 90개·풀이 90개 ID가 일치한다.
- 관리자 기본 ZIP에 진단·추천 문제·정답·풀이를 포함한다. 실제 내려받은 ZIP을 다시 열어 PDF 바이트와 페이지를 확인했다.
- 추천 유형 0/1/2/3개 및 다수 오답: 문제·풀이 각각 0/3/6/9개. 출처·변형 ID가 화면과 동일하고 기본 옵션에서 ‘준비 중인 부록 제외’ 문구가 없다.
- 별도 선택 옵션인 **원문 30문항 상세 풀이**는 기존 3~4회 준비 상태를 유지한다. 이번에 완성한 90개 유사문제 풀이와 구분한다.
