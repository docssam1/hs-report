# 모의고사 진단 분석지와 상세풀이 연결 기준

사용자 확정 기준 · 2026-09-09

## 자료실과 로드맵은 같은 성적표를 연다

- 자료실과 로드맵은 진입 위치만 다르다. 같은 학생·시험·회차는 같은 진단 분석지, 석차 백분율, 누적 결과를 본다.
- 성적표를 열었다는 이유로 성적·재응시·백분율을 새로 저장하지 않는다.
- 기존 회차별 최초 성적과 누적 대상 규칙을 유지한다. 재응시를 최초 성적으로 대체하거나 두 진입 경로를 서로 다른 응시로 집계하지 않는다.
- 자료실에서는 개인 이름이 붙은 `진단 분석지`를 먼저 안내한다. 재원생에게 기존 성적을 다시 입력하도록 요구하지 않는다. 온라인 학생의 입력은 별도 행동으로 유지한다.
- 같은 화면에서 로그아웃 후 다른 학생이 들어오면 링크와 이름도 함께 갱신한다.
- 성적이 없으면 미등록으로 표시한다. 0점이나 백분율 100%로 대신하지 않는다.
- 학생 화면에 참여 인원이나 절대 등수를 표시하지 않는다.
- 문항별 교재 연결표는 기존 연결을 유지한다. 새 연결표를 중복 생성하지 않는다.

## 풀이 완성 기준은 파이널 1회

짧은 정답 설명이나 영상 링크만으로 상세풀이 완료를 선언하지 않는다.

1. **읽을 조건:** 무엇을 구하는지, 범위·횟수·제외 조건을 아이가 이해할 수 있게 짚는다.
2. **풀이 방법:** 왜 이 방법을 쓰는지 설명한다. 필요한 경우 피자를 나누는 상황처럼 이해를 돕는 이야기를 쓰되 문제 조건은 바꾸지 않는다.
3. **단계별 과정:** 실제 문제의 수를 넣어 중간 계산과 판단을 빠짐없이 설명한다. `계산하면` 한마디 뒤에 정답만 붙이지 않는다.
4. **그림과 표:** 수직선·논리표·접기·도형 분할이 핵심이면 해당 표현을 함께 제공한다. 사용자 필기와 강의의 풀이 방법을 우선 참고한다.
5. **답 확인:** 구한 답을 모든 조건에 다시 넣어 확인한다. 단위와 복수 정답·한 가지 답만 적어도 되는 조건을 지킨다.
6. **주의할 점:** 그 문항에서 실제로 놓치기 쉬운 조건을 구체적으로 설명한다. 모든 문항에 같은 조언을 반복하지 않는다.

검수한 정답과 풀이의 답이 일치해야 한다. 사용자 필기·강의와 기존 답이 다르면 별도로 검산하며, 확인되지 않은 풀이를 공개 완료로 표시하지 않는다. 실제로 열람하지 않은 강의를 들었다고 서술하지 않는다.

## 공동 사용과 인쇄

- 파이널 1회의 승인된 상세풀이 30문항은 기존 데이터와 렌더러를 그대로 사용한다.
- 다른 회차도 같은 완성 기준으로 확장하되 짧은 기존 해설을 상세풀이로 재분류하지 않는다.
- 진단지에서 읽는 풀이와 인쇄되는 풀이가 같아야 한다. 인쇄만으로도 이해할 수 있어야 하며 워터마크를 유지한다.
- 연결 경로 변경, 풀이 콘텐츠 검수, 배포 완료는 서로 다른 완료 항목이다. 연결을 통일했다는 이유로 모든 회차의 상세풀이까지 완성되었다고 보고하지 않는다.

## 회귀 검사

- `qa/library-roadmap-report-parity-validate.js`: 자료실·로드맵의 같은 진단 결과, 누적 결과, 파이널 1회 상세풀이 30개, 미등록, 학생 전환, 중복 저장 방지.
- `qa/final-last-route-unit-validate.js`: 정상 회차와 이전 주소의 회차 해석, 개인 이름 전달, 외부 주소 보호.
- `qa/final-last-links-browser-validate.js`: 파이널·최종 경로, 답안 접근, HTML/PDF 구분, 모바일.

검사는 가상 학생과 가상 성적을 사용한다. 실제 학생의 성적이나 승인 상태를 수정하지 않는다.

## 이번 연결 수정과 별도로 남은 항목

- 현재 파이널 2~4회 공개 데이터에는 기존 통계 값은 있으나 `populationStatsVerified()`가 요구하는 확인 정보가 없다. 이 회차들은 누적 백분율에서 제외된다. 자료실·로드맵 결과가 같다는 검사 통과는 누적 대상 전체가 완성되었다는 뜻이 아니다.
- 사용자가 제공한 2024 파이널 회차별 확정 자료는 보존되어 있다. 원자료를 다시 요구하거나 기존 통계 값을 임의 승인하지 말고, 기존 확정 자료와 운영 연결을 복구하는 작업으로 이어간다.
- 상세풀이 완성도는 별도 과제다. 현재 파이널 1회 30문항은 승인된 상세풀이이며, 다른 회차의 짧은 설명과 이전 작업 폴더의 미반영 후보를 동일한 완료 상태로 취급하지 않는다.
