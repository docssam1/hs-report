# 중등 모의고사 진단·처방·약점 학습 적용 지침

작성일: 2026-09-06

참고 시스템: 황소 초등 파이널 1회

범위: 학생별 진단, 교재·강의 연결, 약점 유사문제, 상세풀이, 선생님 코멘트, 인쇄

제외: 석차, 석차 백분율, 컷 백분율 및 이를 계산·저장·반영하는 기능

## 1. 이번 전달의 목적과 경계

파이널 1회의 화면을 복사하는 것이 아니라, **학생의 실제 답안에서 다음 학습까지 이어지는 구조**를 중등 모의고사에 적용한다.

```text
선생님이 학생·시험 선택 → 맞은 문제 체크 → 성적 저장
  → 학생 개인 진단지
  → 먼저 복습할 문항과 약점 유형
  → 연결 교재·강의·상세풀이
  → 오답 문항마다 검수한 유사문제 3개
  → 해설 없이 다시 풀고 설명하기
```

- 이 문서는 전달용 설계·구현 지침이다. 중등에 이미 적용됐다는 완료 보고가 아니다.
- 이번 문서 작성에서는 중등 저장소·학생 기록·서비스를 변경하지 않았다. 중등의 현재 구현 상태는 담당자가 실제 작업본에서 확인한다.
- 기존 중등 성적표에 석차 기능이 있더라도 이번 작업 때문에 제거하거나 수정하지 않는다. 새 진단·처방 모듈이 그 기능에 의존하지 않게 한다.
- 초등의 문항 내용, 학생 기록, 배점, 문항 수, 정답률, 등급명과 컷 점수를 중등에 복사하지 않는다.
- 새로운 등급·컷 산정도 이번 필수 범위가 아니다. 중등의 승인된 기존 점수 기준은 별도 기능으로 유지한다.
- 기존 초등·필즈·중등 프로그램과 승인 흐름을 보존한다. 문서 전달만으로 배포나 기존 데이터 변경이 승인된 것은 아니다.

## 3. 먼저 중등에서 확인할 자료

담당자는 아래 항목을 확인해 `확인됨 / 확인 필요 / 미등록`으로 기록한다. 현재 없는 자료를 있다고 가정하지 않는다.

1. 실제 작업 저장소, 브랜치, 기존 변경 사항, 해당 프로젝트의 운영 지침.
2. 적용할 첫 모의고사와 원본 시험지·공식 답안·선생님 필기·강의의 연결 관계.
3. 시험별 문항 수·만점·문항별 배점·부분점수 여부·복수 정답 허용 조건.
4. 사용자가 승인한 분류표와 문항별 대영역·소영역·세부유형.
5. 문항별 확정 정답률과 해당 버전. 없으면 없는 상태로 둔다.
6. 학생별 공식 성적과 연습 기록의 구분, 선생님 입력 권한, 학생 본인 조회 권한.
7. 교재명·단원·쪽수·문항·강의 시작 위치의 실제 연결 정보.
8. 오답별 유사문제 3개와 각 문제의 정답·상세풀이·그림 검수 상태.

첫 회차를 끝까지 검수한 뒤 다른 회차로 확장한다. 구조만 연결한 회차를 학습 준비 완료로 표시하지 않는다.

## 4. 성적 입력과 학생 진입

### 선생님

- 관리자 화면에서 학생과 회차를 고르고 **맞은 문제를 체크**한다. 학생 계정으로 반복 로그인하게 하지 않는다.
- 저장 전 맞은 문제 수·틀린 문제 수·점수·시험명을 함께 보여준다.
- 미체크를 오답으로 확정하는 것은 선생님이 검토 후 저장할 때다. 아직 저장되지 않은 빈 입력은 0점 성적이 아니다.
- 부분점수가 있는 시험은 O/X만으로 점수를 확정하지 않는다. 기존 채점 규칙에 맞게 문항별 득점을 입력·검증한다.
- 최초 공식 성적, 수정 이력, 연습 응시를 구분한다. 연습 결과가 최초 성적을 덮어쓰지 않게 한다.
- 학생별 결과 옆에 `성적표·코멘트` 진입을 둔다.

### 학생

- 기존 로드맵에 `[학생 이름] 학생의 [시험명·회차] 성적표` 버튼을 둔다.
- 성적이 없으면 `아직 등록되지 않았습니다.`라고 표시한다.
- 통신 실패를 미등록이나 0점으로 바꾸지 않는다.
- 학생은 자기 성적표와 배정된 약점 학습으로 바로 들어간다.
- 이름·URL·브라우저 저장값만으로 본인 권한을 인정하지 않는다. 실제 데이터 조회·저장에서도 권한을 확인한다.

## 5. 진단지의 구성

화면은 표지 없이 바로 읽을 수 있게 한다. 인쇄 표지는 별도로 둔다.

1. 학생 이름·시험명·회차·점수·맞은 문제 수·오답 수.
2. 위쪽 `docssam 코멘트`: 선생님이 실제 수업에서 관찰한 내용.
3. 영역별 학습 결과: 영역별 득점·배점·맞은 문제·틀린 문제.
4. 배점대별 학습 결과.
5. **문항별 진단 — 배점대별 학습 결과 바로 아래.**
6. 잘한 점, 다시 살펴볼 영역, 먼저 복습할 문제와 점수 보완 목표.
7. 개인별 3단계 학습 계획.
8. 오답 교재·강의 연결표와 유사문제 학습 버튼.
9. 해당 시험의 상세답안.

문항별 진단에는 시험 문항 번호, O/X 또는 득점 상태, 배점, 확정 정답률, 대영역·소영역·세부유형, 다시 확인할 조건을 표시한다. 우선 복습 문항에는 옅은 파랑과 `★ 꼭 다시 맞히기`를 함께 표시한다. 흑백 인쇄에서도 별표와 글자로 구분되어야 한다.

## 6. 진단 기준: 점수로 틀린 원인을 단정하지 않기

### 서로 다른 수치

- **문항 정답률:** 승인된 기준 자료에서 해당 문제를 맞힌 비율. 새 학생 성적이 들어와도 자동 변경하지 않는다.
- **개인 영역 득점률:** 그 학생의 영역 득점 ÷ 해당 영역 배점 × 100.
- **개인 배점대 득점률:** 그 학생이 해당 배점대에서 얻은 점수 ÷ 해당 배점대 총점 × 100.
- **석차 백분율:** 이번 이식 범위에서 사용하지 않는다. 문항 정답률과 비교해 복습 문제를 고르지 않는다.

온라인 학생도 확정 정답률을 볼 수 있어야 한다. 석차 서비스나 통계 조회에 실패했다는 이유로 정답률까지 숨기지 않는다. 정답률이 없으면 `정답률 미등록`으로 표시하고 0%·추정값·초등 값을 넣지 않는다. 0%는 유효한 값이므로 미등록과 구분한다.

### 먼저 복습할 문제 선정

현재 파이널 1회의 기준은 다음과 같다. 중등에서도 출발 기준으로 검토하되 시험별 설정으로 분리한다.

1. 해당 영역에 2문항 이상 있고 개인 영역 득점률이 70% 이상이면 이번 시험에서 확인한 강점 영역 후보로 본다.
2. **강점 영역에서 틀렸고, 확정 정답률이 70% 이상인 문제를 우선한다.** 그 후보 사이에서는 정답률이 높은 문제를 먼저 둔다.
3. 다음은 이미 맞힌 같은 세부유형의 문제가 있는 오답이다. 분류 확인이 끝난 문항끼리만 연결한다.
4. 다음은 강점 영역의 다른 오답이다.
5. 나머지는 낮은 배점, 문항 번호 순으로 정리하되, 낮은 배점만으로 쉽다거나 반드시 맞힐 수 있다고 설명하지 않는다.
6. 우선 복습은 최대 3문제로 시작한다. 오답이 적으면 실제 개수만 제시한다.

주의: 위 70%는 **복습 후보를 고르는 기준**이지 문제은행 난이도 5단계의 경계값이 아니다. 중등 기준을 조정할 경우 교사 승인과 설정 버전을 남긴다.

- 한 문제만으로 영역 전체를 잘하거나 못한다고 단정하지 않는다.
- O/X만으로 `계산 실수`, `집중력 부족`, `개념을 모름`을 실제 원인으로 기록하지 않는다.
- 자동 조언은 `분모를 같게 바꾸는 단계부터 다시 확인해 보세요.`처럼 확인할 행동으로 쓴다.
- 실제 관찰은 선생님 코멘트에서 따로 기록한다.
- 자료가 부족하면 그 범위에서만 설명한다. 이전 시험 기록이 없는데 반복 약점이라고 하지 않는다.

## 7. 유형과 교재 연결

유형은 **대영역 → 소영역 → 세부유형**으로 관리한다. 기존 중등의 승인된 분류표와 식별자를 우선 사용한다.

세부유형명에는 학생이 구별해야 할 조건이 들어가야 한다. 다음은 명명 방식의 예이며 중등의 확정 분류표가 아니다.

- `방정식` → `분모에 수가 있는 일차방정식에서 분모 없애기와 부호 처리`
- `닮음` → `평행선이 있는 삼각형에서 대응변을 찾아 길이의 비 세우기`
- `경우의 수` → `서로 다른 두 대상을 고를 때 순서를 구별하지 않는 경우`

같은 유형 연결은 표시 글자의 유사성만으로 판단하지 않는다. 대영역·소영역·세부유형의 승인된 연결 또는 안정적인 유형 식별자를 사용한다. 분류명 변경 시 기존 기록과의 연결을 보존한다.

교재 연결표의 기본 열:

`시험 문항 번호 | 세부유형 | 다시 확인할 개념·풀이 방법 | 교재·단원·쪽수·문항 | 강의 보기 | 유사문제 풀기`

- 쪽수와 영상 시작 시각은 실제 자료에서 확인한 값만 넣는다.
- 강의가 없으면 상세풀이만으로 공부할 수 있어야 한다.
- 링크 승인에는 기존 서재 흐름을 재사용한다. 같은 목적의 별도 승인 페이지를 새로 만들지 않는다.
- 유형이 둘 이상 연결돼도 같은 문항을 여러 번 집계하거나 같은 약점에 점수를 중복 합산하지 않는다.

## 8. 개인별 3단계 학습 처방

### 1단계 · 되찾을 점수부터

- 6절의 우선 복습 문항 최대 3개.
- 조건을 표시하고, 먼저 해설 없이 식·표·그림으로 다시 푼다.
- 막힌 단계만 상세풀이와 비교한 뒤 처음부터 다시 설명한다.
- 완료 기준: 정답뿐 아니라 왜 그 식이나 그림을 쓰는지 도움 없이 설명한다.

### 2단계 · 반복 약점 보완

- 실제로 저장된 다른 시험의 공식 기록에서 같은 세부유형의 오답을 확인한다.
- 1단계에서 이미 고른 문항은 다시 넣지 않는다. 현재 파이널 기준은 최대 3문항이다.
- 개념·교재 예제 확인 → 이번 오답 다시 풀기 → 검수된 유사문제 3개 → 다음 날 다시 설명하기.
- 이전 기록이 없거나 해당 문항이 없으면 반복 약점을 만들어 내지 않는다. 1단계 문항을 다시 확인하는 계획으로 안내한다.

### 3단계 · 다음 수준 도전

- 앞 단계가 끝난 뒤 강점 영역 안에서 조건이 달라진 문제를 제시한다.
- 현재 파이널은 앞 단계에 없는 오답 중, 분류가 확인되고 이미 맞힌 같은 유형이 있는 문제를 최대 2개 고른다.
- 조건에 맞는 문항이 없으면 선생님이 도전 문제를 고르게 한다. 억지로 빈 단계를 채우지 않는다.
- 완료 기준: 달라진 조건과 기존 풀이에서 바꿔야 하는 부분을 설명한다.

15~20분, 20~25분 같은 시간은 권장 계획일 뿐 실제 풀이 시간을 측정한 결과가 아니다. 중등의 문항 길이와 학생 상태에 맞춰 조정한다. 자기 체크만으로 공식 성적·진도·완료 상태를 자동 변경하지 않는다.

### 점수 보완 목표와 그래프

`현재 점수 + 선택한 서로 다른 오답의 회복 가능한 배점 = 해당 문제를 모두 해결했을 때의 목표 점수`

- 이번 시험의 해당 오답만 바로잡고 나머지 답안은 그대로일 때의 계산이다. 다음 시험 성적을 예측하거나 상승을 보장하는 표현은 쓰지 않는다.
- 부분점수가 있다면 문항 배점 전체가 아니라 `배점 − 이미 얻은 점수`만 더한다.
- 여러 단계에 같은 문항을 중복 합산하지 않으며 만점을 넘지 않는다.
- 새 유사문제를 맞힌 점수를 기존 시험에 더하지 않는다.
- 현재 점수와 단계별 목표는 같은 눈금의 막대그래프로 비교한다. 영역별 득점률도 막대나 기존 그래프로 함께 보여준다.
- 그래프의 만점은 시험 설정에서 읽는다. 초등 코드의 100점 고정 눈금을 그대로 쓰지 않는다.

## 9. 오답 유사문제와 문제은행

### 원칙

- **틀린 시험 문항마다 검수된 서로 다른 유사문제 3개를 고정 등록한다.** 유형 분류표만 만든 상태를 문제은행 완성이라고 하지 않는다.
- 3개 모두 같은 핵심 개념·풀이 방법을 연습해야 한다. 숫자 변경으로 조건이 무너지거나 별개의 풀이가 필요해지면 다시 검수한다.
- 문제·조건·그림·정답·상세풀이를 한 문항 기록으로 연결한다.
- 원본은 사용자가 제공한 실제 시험 자료다. 생성한 시험지를 원본으로 취급하지 않는다.
- 검수가 끝나지 않은 문항은 선택·인쇄하지 않는다. 빠진 1개를 다른 유형의 문제로 몰래 채우지 않는다.
- 자료 부족 시 준비된 문항과 보류 문항을 구분하고, 준비되지 않은 오답까지 학습 완료 범위에 포함하지 않는다.

### 학생의 선택 흐름

- 기본 진입은 시험지 형태의 학습 화면이다. 생성기나 DB 현황을 먼저 보여주지 않는다.
- `전체 오답`과 실제 중등 시험의 배점대별로 고를 수 있게 한다. 초등의 2.7·3.4·4.2를 중등에 고정하지 않는다.
- 배점대는 유사문제의 임의 점수가 아니라 연결된 시험 문항의 배점 기준이다.
- 원하는 영역·여러 세부유형도 고를 수 있다. 학생용 범위는 현재 학생·시험의 실제 오답 안에 한정한다.
- 유형 사이에 1번 변형들을 먼저 배치하고 다음 변형들을 배치하는 등 서로 섞어 연습한다.
- 한 번 확정한 구성은 다시 열기·인쇄 전환 후에도 문항·숫자·순서·답안이 같아야 한다.
- 같은 유형의 시험 문항을 여러 개 틀렸더라도 실제 시험 문항 번호와 개별 유사문제 식별자를 유지한다. 같은 유사문제를 중복 인쇄해 3개씩을 채웠다고 하지 않는다.

### 교사용 찾기

- `시험지로 찾기`, `유형으로 찾기`를 중심으로 한다. 연결 교재가 있으면 교재 단원별 탐색도 재사용한다.
- 승인된 지문·유형명·검색어로 찾고, 권한 없는 지문은 검색 결과에 노출하지 않는다.
- 필터를 바꿔도 이미 선택한 문항을 조용히 지우지 않는다. 현재 결과 밖의 선택도 요약에서 확인·해제할 수 있게 한다.
- 난이도는 정답률이 있으면 승인된 기준으로 최상·상·중간·하·최하를 구분하고, 없으면 배점 기준임을 표시한다. 5단계 경계는 중등 담당자가 확인한다.
- 시험 문항 정답률을 유사문제의 실제 측정 정답률처럼 표시하지 않는다.
- `더 쉽게/더 어렵게`는 별도 검수 문항군이 있을 때만 제공한다. 고정 3문제를 즉석 생성으로 바꾸는 스위치가 아니다.

## 10. 상세풀이 제작 규칙

영상이 없는 유사문제도 종이 답안만으로 따라갈 수 있어야 한다.

1. **읽을 조건:** 지문에서 무엇을 구별해야 하는지 실제 문구와 연결한다.
2. **풀이 방법:** 왜 그 식·표·그림이 필요한지 설명한다.
3. **단계별 계산:** 해당 문제의 숫자로 중간 과정을 보여준다.
4. **정답 확인:** 조건에 다시 넣어 확인하고 단위·범위·경우 누락을 점검한다.
5. **다음에 주의할 점:** 일반적인 잔소리가 아니라 이 유형에서 놓치기 쉬운 조건을 짚는다.

- 선생님 강의와 필기 답안의 유효한 풀이 방법·설명 순서를 반영한다. 계산이나 조건 해석 오류는 그대로 복제하지 않는다.
- 수직선이 핵심이면 수직선을, 경우 나누기가 핵심이면 필요한 표를 풀이에 넣는다. 문제 본문에 답을 암시하는 장식용 표는 넣지 않는다.
- 실제 그림이 있는 문항은 원본 그림 또는 충분히 충실하게 재현하고 검수한 그림을 사용한다. 글로 상상한 임의 도형으로 대신하지 않는다.
- 예시 이야기는 개념을 이해하는 데 도움이 될 때 사용하되 수학적 조건과 정답을 바꾸지 않는다.
- 복수 정답, 하나만 적어도 되는 답, 모두 적어야 하는 답을 구분한다. 답 하나를 누락하거나 임의로 단일 정답 처리하지 않는다.
- 정답만 독립 계산한 것으로 검수를 끝내지 않는다. 풀이의 각 단계·그림·조건·최종 답이 함께 맞아야 한다.

## 11. 코멘트와 기록 보호

- 선생님 코멘트는 학생·시험·회차에 연결하고 위쪽에 둔다. 학생은 자신의 저장된 코멘트를 읽는다.
- 성적 저장과 코멘트 저장은 독립시킨다. 코멘트 수정이 점수·답안·정답률을 다시 저장하지 않게 한다.
- 저장 중 중복 클릭 방지, 저장 성공 표시, 실패 시 입력 보존, 다른 곳에서 수정한 내용과의 충돌 처리가 필요하다.
- 단순 미리보기에는 코멘트 칸을 숨긴다. 실제 학생 성적표에는 저장 권한이 있는 선생님에게 입력칸을 보여준다.
- 학생을 바꾸거나 늦은 응답이 도착해도 이전 학생의 코멘트가 섞이지 않아야 한다.
- 교사 권한과 저장된 성적 연결을 확인한 뒤 저장한다. 화면에서 버튼을 숨기는 것만으로 보호했다고 하지 않는다.
- 응시 인원, 다른 학생 이름·성적, 보호된 원본·답안·개인 자료를 공개 파일이나 공용 응답으로 노출하지 않는다.

## 12. 디자인과 출력

지필드 공용 스킬 `gfield-design-system`의 `SKILL.md`, `references/design-rules.md`, `references/question-bank-ui.md`를 읽고 중등의 해당 화면에만 적용한다.

- 흰 종이, 차분한 회색 배경, 읽기 쉬운 진한 글자, 파란 주 행동을 기본으로 한다. 주황색 버튼·누런 표지·장식용 대시보드를 기본값으로 복제하지 않는다.
- 화면의 진단지는 표지를 생략해 바로 읽게 한다.
- **진단 패키지 인쇄/PDF:** 표지 → 진단지·학습 계획 → 교재 연결표 → 상세답안 순서로 한 세트.
- **유사문제 학습지 인쇄:** 문제만 / 답안·풀이만 / 둘 다 / 빠른 정답만을 구분한다. 학생에게 허용되지 않은 답안 모드는 열지 않는다.
- 약점 학습지 표지에는 학생명·시험명·회차, 실제 시험 문항 번호와 세부유형, 해결 여부 셀프 체크를 둔다. 유형 목록은 두 열로 정리하되 긴 이름은 줄바꿈한다.
- 초등의 기본 학습지는 2단·한 페이지 6문제·같은 행 간격·칸 위쪽 시작이다. 중등의 긴 지문·증명·큰 도형은 실제 A4에서 확인해 큰 칸이나 별도 페이지를 사용한다. 무조건 6문제에 맞춰 축소하지 않는다.
- `둘 다`의 양면용 출력은 표지를 포함한 문제 부분이 홀수 페이지일 때 빈 면을 넣고, 답안·풀이를 새 종이 앞면에서 시작한다.
- 답안만·빠른 정답만에 불필요한 문제 표지나 양면 공백을 넣지 않는다.
- 표지·진단지·연결표·문제·빠른 정답·풀이 모두 지필드 워터마크 필수. 양면용 빈 면만 제외한다.
- 실제 PDF의 페이지 수, 잘림, 답안 시작 면, 문제와 답안 번호를 확인한다. 브라우저 화면 검사만으로 인쇄 검수를 대신하지 않는다.

## 13. 구현 시 분리해야 할 지점

아래는 현재 초등 코드의 특징을 그대로 옮겼을 때 생길 수 있는 문제다.

| 현재 초등 구현 | 중등 적용 지침 |
| --- | --- |
| 진단 모듈에 `verifyPopulation`, `populationVerified`, `percentile` 관련 분기가 있음 | 정답률 검증과 학생 개인 진단을 독립시킨다. 석차 계산·표시 분기는 이식하지 않는다. 함수 이름만 바꾸지 말고 실제 의존성을 제거한다. |
| 일부 점수 검증·그래프가 100점 기준, 화면은 30문항 기준 | 시험 설정의 만점·문항 수·배점으로 검증·표시한다. |
| 같은 유형 비교에 영역·소영역·유형 문자열을 사용 | 중등의 승인된 식별자 연결을 우선하고 미확인 분류는 같은 유형이라고 단정하지 않는다. |
| 일부 약점 표시가 문항의 원래 영역 필드를 참조 | 집계에 사용한 정규화된 분류와 화면의 문항 목록을 일치시킨다. |
| 고정 은행이 `final1-qNN`, 30×3문항 구조 | 중등의 기존 식별자를 보존하고 시험별 문항 수×3으로 연결한다. 초등 전용 ID를 재사용하지 않는다. |
| 코멘트와 백분율 기능이 일부 같은 호출 경로에 묶여 있음 | 코멘트 계약만 기존 중등 기능에 맞춰 연결한다. 백분율 기능·원본 비교 자료를 함께 복제하지 않는다. |
| 현재 오답 화면 일부 문구가 `전체문제` | 새 중등 학생 화면에서는 범위가 분명한 `전체 오답`으로 쓴다. |

최소 데이터 계약은 기존 중등 구조에 맞춰 정한다. 새 DB를 먼저 만드는 것이 목적이 아니다.

- 시험: 안정적인 시험 ID, 버전, 문항 수, 만점, 배점·부분점수 규칙.
- 문항: 시험 문항 ID·번호, 배점, 승인된 유형 연결, 정답률 또는 미등록, 답 계약, 검수 상태.
- 결과: 기존 학생 ID, 시험 ID, 공식/연습 구분, 문항별 결과, 저장 버전.
- 처방: 해당 결과 버전, 선택한 시험 오답 ID, 유사문제 ID 3개, 자료 연결, 확정 순서.
- 코멘트: 학생·시험 연결, 내용, 수정 주체·시각 또는 충돌 확인 버전.

사용자에게는 생성기 ID·검수 버전 같은 내부 정보 대신 학습에 필요한 시험 번호와 유형을 보여준다.

## 14. 구현 순서와 완료 기준

### 단계 A · 중등 자료 연결표

- 한 회차의 원본·정답·배점·유형·교재·강의·정답률을 확인한다.
- 확인이 끝나지 않은 문항과 항목을 분리한다.
- 현재 중등에 있는 기능과 새로 필요한 기능의 차이만 목록으로 만든다.

### 단계 B · 성적 입력 → 개인 진단

- 맞은 문제 체크, 공식/연습 구분, 본인 성적표 진입.
- 배점대 바로 아래 문항별 진단, 확정 정답률, 강점 영역의 우선 복습 표시.
- 석차 관련 호출 없이도 진단이 완성되는지 확인한다.

### 단계 C · 처방 → 상세풀이 → 3문제

- 실제 자료에 연결한 개인별 3단계 계획.
- 선생님 설명을 반영하고 검수한 상세풀이.
- 선택한 오답 문항마다 서로 다른 유사문제 3개, 정확한 문제·답안 연결.
- 검수되지 않은 문항은 잠금 유지.

### 단계 D · 코멘트·인쇄·회귀 검사

- 코멘트 저장은 다른 기록을 바꾸지 않음.
- 진단 패키지와 유사문제 인쇄 4모드의 실제 PDF 확인.
- 기존 중등 기능과 다른 프로그램이 그대로 동작함을 확인.

### 반드시 통과할 검사

- [ ] 성적 미등록, 통신 실패, 0점, 만점이 서로 다른 상태로 표시된다.
- [ ] 중등의 실제 배점 합·만점·문항 수가 맞고 부분점수도 보존된다.
- [ ] 문항 정답률이 새 성적 저장·코멘트 저장으로 바뀌지 않는다.
- [ ] 석차·컷 백분율 없이 정답률·진단·처방·그래프가 동작한다.
- [ ] 약한 영역의 정답률 99% 오답보다 강점 영역의 정답률 85% 오답을 우선하는 사례를 확인한다.
- [ ] 강점 근거가 부족하거나 정답률이 없는 사례를 과장하지 않는다.
- [ ] 과거 성적이 없으면 반복 약점을 만들어 내지 않는다.
- [ ] 단계별 목표 점수에 같은 문항이나 유사문제 점수를 중복 합산하지 않는다.
- [ ] 실제 오답만 배정되고 배점·유형 필터로 맞은 문항이 섞이지 않는다.
- [ ] 오답별 3문항의 독립 정답 계산, 풀이 단계, 그림·지문 대조가 모두 끝났다.
- [ ] 다시 열기·인쇄 전환 후 문항·숫자·순서·답안이 같다.
- [ ] 다른 학생 자료 접근, 권한 없는 코멘트 저장, 늦은 응답의 학생 혼합을 막는다.
- [ ] 코멘트 저장 실패 시 입력 보존, 동시 수정 충돌 처리를 확인한다.
- [ ] 실제 데스크톱·390px·키보드 조작에서 읽기와 입력이 가능하다.
- [ ] A4/PDF에 워터마크·문제/답안 번호·양면 답안 시작 면이 맞는다.
- [ ] 문서 작성, 로컬 구현, 수학 검수, 화면·인쇄 검사, 커밋·푸시·운영 확인을 따로 보고한다.

참고 검사 파일: `qa/final-diagnostic-comment-validate.js`, `qa/final-correct-entry-validate.js`, `qa/final-personal-roadmap-validate.js`, `qa/final-wrong-practice-validate.js`, `qa/final1-fixed90-math-validate.js`, `qa/final1-fixed90-browser-validate.js`, `qa/final-report-ui-validate.js`, `qa/final-report-package-validate.js`. 검사 방식만 참고하고 초등 전용 수치·답을 중등 기대값으로 복제하지 않는다.

## 15. 다른 작업자에게 넘길 때

이 문서와 필요한 파일 경로·Git 커밋·중등 인수인계 문서 경로만 전달한다. 기존 대화, 첨부 이미지, 도구 출력, 원본 자료를 함께 복제하지 않는다. 에이전트를 새로 만들도록 별도 요청받은 경우 `fork_turns="none"`을 명시하고 짧고 독립적인 지시만 준다. 생성 직후 세션 크기가 비정상적으로 큰지 확인하고 그러면 중단한다.

최종 목표는 **학생이 자기 시험 결과에서 무엇을 다시 공부할지 이해하고, 실제 교재·풀이·검수된 3문제로 이어서 공부할 수 있는 상태**다. 점수와 분류만 표시하는 것으로 완료하지 않는다.
